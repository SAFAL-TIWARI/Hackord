Add a new feature called **Hackathon Explorer** to the existing platform.

This feature should be a dedicated page where an AI agent automatically discovers and updates hackathons from across the internet. The AI continuously monitors trusted platforms such as Devfolio, Unstop, Devpost, ETHGlobal, DoraHacks, MLH, HackerEarth, Hack2Skill, Luma, and official organizer websites, then aggregates them into one searchable hub. The system should automatically detect new hackathons, remove duplicate listings, update deadlines if organizers make changes, and categorize events by domain.

Design a modern, responsive SaaS interface with a search bar, filters, and beautiful hackathon cards.

Each hackathon card should display:

* Banner
* Hackathon Name
* Organizer
* Prize Pool
* Online/Offline
* Registration Deadline
* Submission Deadline
* Team Size
* Tags (AI, Web3, IoT, Cybersecurity, etc.)
* Bookmark button
* Share button
* View Details button
* **Create Team Room** button

Clicking **Create Team Room** should automatically create a new room inside the platform by pre-filling the hackathon name, organizer, banner, registration deadline, submission deadline, result date, and team size. The user should only need to confirm the room creation instead of entering all details manually.

Include an **AI Recommendations** section that suggests hackathons based on the user's skills, profile, interests, GitHub technologies, and previous hackathon participation.

Add an AI-powered natural language search so users can search with queries like:

* "AI hackathons closing this week"
* "Web3 hackathons with a ₹5L+ prize pool"
* "Beginner-friendly online hackathons"

Include a calendar view showing registration, submission, and result dates. Allow users to bookmark hackathons, receive notifications when deadlines change, when registrations are about to close, or when new hackathons matching their skills are discovered.

This feature should integrate seamlessly with the existing dashboard and become the primary place for users to discover hackathons and instantly start building teams.
