## 🚀 Overview
**Hackord** is a modern, high-performance web platform designed specifically for hackathon participants. It helps teams form quickly, collaborate efficiently in dedicated "Rooms", and track project deadlines in real-time. 

## ✨ Key Features
- **Team Rooms:** Dedicated workspaces for teams with GitHub integration.
- **Live Dashboard:** Real-time activity streams and upcoming hackathon deadlines.
- **Quick Notes:** Built-in scratchpad for brainstorming and quick links.
- **AI Integration Ready:** Designed to hook into generative models for pitch deck creation.
- **Modern UI/UX:** Built with a stunning dark-mode glassmorphism interface and subtle 3D interactions.

## 🛠️ Tech Stack
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing:** [TanStack Router](https://tanstack.com/router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Components:** [Radix UI](https://www.radix-ui.com/) + Custom Glass UI
- **3D Graphics:** [Three.js](https://threejs.org/) + React Three Fiber

## 🚦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/hackord.git
   cd hackord
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **View the app:**
   Open [http://localhost:5174](http://localhost:5174) in your browser.

## 📁 Project Structure
- `/src/components` - Reusable UI elements (AppShell, SpotlightCard, etc.)
- `/src/routes` - File-based routing via TanStack Router
- `/src/lib` - Utility functions, API mockups, and state management
